1. Executive Summary & Core Capabilities

AgroScan Sentinel is an advanced AI-powered Agricultural Decision Support System (DSS) engineered to deliver real-time crop disease diagnosis, multispectral leaf pathology classification, IoT sensor microclimate telemetry, GPS geospatial outbreak mapping, and agronomist consultation dispatching.

🔬 Neural Leaf Diagnostic Scanner
Simulated deep learning foliar analysis classifying phytopathogens against 45,000+ botanical models with localized lesion bounding boxes and severity indexing.
📍 Live GPS Geospatial Sentinel
HTML5 browser geolocation + dual reverse geocoding resolving exact farm area names with layered cartography (Standard, Satellite Earth, NDVI vegetation canopy).
🔐 Dual-Method Authentication Gateway
1-Click Google Workspace (Gmail) SSO and Mobile Phone Number + SMS 4-Digit OTP verification with strict scanner access gating.
🌓 Animated Daylight / Dark Mode
Smooth 180° animated spin theme toggle between high-contrast Daylight Mode (☀️) and deep obsidian Dark Sentinel Mode (🌙).

3. System Architecture & Data Flow

The platform follows a modular client-server decoupled architecture designed for high availability, offline capability, and low latency:

[ CLIENT SPA (React 18 + Vite) ] ├── UI Views: Dashboard, Analysis Report, Field Map, Crop Encyclopedia, Community Hub ├── Security & Auth: Gmail SSO & Mobile SMS OTP Gate ├── Geolocation Engine: HTML5 Navigator GPS + Nominatim Geocoder └── State Manager: agroscanStore.js (LocalStorage Reactive Store) ↕ (HTTP REST / JSON over Port 5000) [ BACKEND SERVER (Node.js + Express) ] ├── Auth Controller: /api/auth/login, /api/auth/register ├── Neural AI Scan Engine: /api/scan (Multispectral classification simulation) ├── Telemetry & Sensor Pipeline: /api/sensors, /api/sensors/update ├── Outbreak Notification Dispatcher: /api/alerts └── Distribution Service: /api/download-zip (Live ZIP distribution) ↕ [ HYBRID DATABASE ROUTER ] ├── Primary File Store: server_db.json (Zero-Setup Portability) └── Cluster Store: MongoDB Atlas / Local via Mongoose ODM

4. Core Functional Modules Deep-Dive

4.1. AI Leaf Diagnostic Scanner (QuickScanModal.jsx & AnalysisReportScreen.jsx)

  • Specimen Ingestion: Supports high-definition photo upload, live camera feed, or calibrated field specimens.
  • Neural Inference Simulation: Computes foliar chlorophyll spectral bands, lesion density, and pattern matches against 45,000+ pathogen models.
  • Lesion Bounding Boxes: Overlays color-coded bounding boxes highlighting primary necrotic lesions and spore clusters with confidence percentages (e.g. 98.4%).
  • Prescriptive Action Guides: Generates multi-step systemic chemical fungicide sprays, organic soil amendments, and perimeter quarantine instructions.

4.2. Live GPS Geospatial Field Sentinel (FieldMapScreen.jsx)

  • Browser GPS Geolocation: Queries device latitude/longitude with high precision.
  • Real-Time Area Resolution: Queries dual reverse geocoding services to display the exact farm name and locality (e.g. "Sector 4B • Iowa Agro-Corridor").
  • Layered Radar Map: Allows switching between Standard Street, High-Res Satellite Earth, and NDVI vegetation false-color layers.

4.3. Dual-Method Authentication Gateway (AuthModal.jsx)

  • Gmail 1-Click Login: Instant Google Workspace authentication.
  • Mobile Number + SMS OTP: Country code selector (🇮🇳 +91, 🇺🇸 +1, 🇬🇧 +44, etc.), phone number entry, and 4-digit verification code with countdown timer.
  • Scanner Access Gating: The diagnostic scanner is locked until authenticated; logging in automatically unlocks and launches the scanner.
